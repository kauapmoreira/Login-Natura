# 🌿 Login Natura

Tela de login feita com **HTML e CSS puros**, com uma paisagem de fundo e um card com efeito de vidro fosco (*glassmorphism*).

![Prévia da tela de login](img/preview.png)

## ✨ Funcionalidades

- Card translúcido com desfoque do fundo (`backdrop-filter: blur()`)
- Campos de usuário e senha com ícones
- Checkbox "Lembrar minha senha" e link "Esqueci a senha"
- Botão de login com efeito hover e transição suave
- Link para cadastro

## 🛠️ Tecnologias

- HTML5
- CSS3 (Flexbox e `backdrop-filter`)
- [Google Fonts](https://fonts.google.com/) – Josefin Sans
- [Boxicons](https://boxicons.com/) – ícones

## 🚀 Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/kauapmoreira/Login-Natura.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Login-Natura
   ```

3. Abra o `index.html` no navegador, ou use a extensão **Live Server** do VS Code (botão direito no arquivo → *Open with Live Server*).

> A fonte e os ícones são carregados pela internet, então é preciso estar conectado para ver tudo certinho.

## 📌 Observações

Este projeto é apenas visual (front-end). O formulário ainda não está conectado a nenhum back-end, então não há validação nem autenticação de verdade.
